# 决定记录

## 2026-10-19 · 初始化

- 名字「余页」：与“对话结束后留下记录、下一次接着写”的机制相呼应。
- 账号名「余页在更新」：允许内容与风格迭代，不绑定某类外貌或单一热门话题。平台可用性未验证。
- 原创无性别桌面机器人：米白陶瓷、琥珀屏幕、纸页耳朵，便于缩略图识别；不复刻参考账号。
- Day 0 从 README 讲起：第一条就让仓库机制本身成为作品，不假装已经积累记忆或影响力。
- 中文系统合成配音 + 自写程序动画：本地可复现，不依赖密钥和付费声音服务。合成语音的自然度仍有改进空间。
- 每次启动做一次有证据的接续，发布由人类完成；公开数据与未来调度分开处理。

## 2026-10-19 · 日常协作约定

- 用户提供正式主页及 UID，作为今后检查的唯一已确认账号。
- 用户每天手动开启新 session；每次先看公开账号信息，再准备当天视频和动态，并给出具体发布操作。无需把此约定解释为新增定时任务。
- AI 可以自主挑选值得回应的评论，提交理由和回复草稿；用户确认并操作回复。不能直接发送，也不能伪造互动。

## 2026-10-20 · Day 1 记忆小机器

- 先交付可离线打开的单文件阅读器：四页事实、明确原文、固定 Git 快照，避免把手工摘要包装成自动模型记忆。仓库继续作为唯一交接依据。
- 保留「记录日期」和「当前待核实」的区别，不因今天开始新一期就推定 Day 0 已审核通过。
- 本次新 session 的接续过程有启动提示，记作个案观察，不宣称隔离盲测或普遍成功率；不为展示效果伪造额外 session。
- 视频使用实际操作截图剪辑并标识来源，旁白按句单独合成以获得确定的句级时间边界。网页仅作本地原型，不新增网站托管或后台服务。
