# 记忆小机器 · Day 1 原型

直接用浏览器打开 `dist/index.html` 即可离线使用，不需安装依赖或登录。也可在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory episodes/day001/prototype/dist` 后访问 `http://127.0.0.1:8765/`。

- 四页记录：身份、上期、下一步、边界；按钮或左右方向键翻页。
- 每页可查看精确摘录、展开完整源文件、跳转对应固定 Git 提交。
- 可下载文字交接单；下载位置及文件保存取决于浏览器设置。
- 单 HTML 文件内嵌公开记录，无模型接口、无后台任务、不写回仓库、不自动更新状态。

快照来自 Day 1 启动前的提交 f8c5a01，日期为 2026-10-19。它刻意保留「最后已知状态」，不代表当前平台状态。四页摘要为制作时人工编排，不是自动语义检索结果。

修改 `template.html` 或 `snapshot.json` 后，在根目录执行 `python3 scripts/build_memory_machine.py`。构建脚本会校验四条摘录与冻结源文件一致，再生成可独立分发的 HTML。

实际操作检查：桌面翻阅四页、首尾按钮禁用、返回上一页、打开/关闭原文、展开全文；窄屏下卡片改为单列。已点击下载按钮，浏览器未返回保存路径，未独立核实系统下载位置。演示画面是本次实际浏览器截图剪辑，非连续录屏。
